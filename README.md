# 极夜钢琴 · Polar Night Piano

库乐队式的网页电子钢琴 + 下落音符练习。电脑和 iPad 都能玩。

**▶ 在线玩：https://yulan32feixiao.github.io/polar-night-piano/**

- 难度 = 琴键数量：入门 8 键（纯白键）/ 初级 13 / 中级 25 / 高级 37 / 全键 61
- 音符按节拍落下，不会停下来等；可调速度（50%–150%）、节拍器、示范
- 电脑键位同库乐队：A S D F… 白键，W E T Y U 黑键，Z / X 换八度，空格开始/暂停
- 全屏按钮，Esc 退出
- 「编辑曲谱」用简谱写曲子，存在本机浏览器，可导出/导入
